# Quick Task — Vitest + Asymmetric Liquidity characterization tests

## Goal

Lock the behaviour of the Asymmetric Liquidity feature (and the recently
shipped B4/B2 reserve-decimal fix) with **pure-logic characterization tests**,
so it cannot silently regress. Zero behaviour changes to product code — the only
source edit is a behaviour-preserving extraction of `toPlancks` into a pure util
so it can be tested without dragging Polkadot into the test runtime.

`lunes-dex-main` currently has **zero** test infrastructure. CLAUDE.md lists
Jest 29 as the intended runner ("none configured yet"); we use **Vitest** here
because it is native to Vite 6 and needs near-zero config for the
styled-components / recharts ESM deps. Noted as a deviation in the commit.

## Behaviour being locked (verified by reading source)

- `reserveUtils.normalizeReservesForPath` — aligns canonical pair reserves to the
  swap path (reserveIn = path[0]); swaps when path[0] is canonical token_1.
- `reserveUtils.humanPrice` — decimal-adjusted price; WLUNES(8dec)/LUSDT(6dec)
  reserves `7_679_233_508 / 81_660_345_758` → **1063.39** (naive ratio is 10.63);
  returns 0 when either reserve is 0.
- `CurveChart.simulateLiquidity` — `max(0, (k + c·L)·(1 − x/x0)^γ − feeT·x − interestR·L)`;
  returns 0 when `x >= x0` or `x0 <= 0`.
- Page `midLiqPreview` with `defaultBuy`/`defaultSell` →
  Buy@30% (`x=3000`) = **334.00**, Sell@30% (`x=2400`) = **237.80**.
- `CurveChart.buildChartData` — 51 points (steps=50), x from 0..max(x0), 4-dp y.
- `STRATEGY_TEMPLATES` — exactly 3 templates; every gamma ∈ [1,5]; positive k/x0.
- `toPlancks(units, decimals=12)` — integer·PLANCKS_PER_UNIT + padded/truncated
  fraction; `try/catch → '0'` on bad input.
